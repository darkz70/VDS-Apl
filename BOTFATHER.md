# Оформление бота в @BotFather

Чтобы бот выглядел официально, вставьте эти тексты в @BotFather
(команды вводятся по одной, без кавычек).

## /setname
```
VDS-Apl | Заявки в команду
```

## /setdescription — короткое описание (лимит 120 символов)
```
Официальный бот заявок VoidSMP · Майнкилд: контент-мейкер, хелпер, редактор Вики (Fandom).
```

## /setabouttext — «О боте» в профиле (лимит 120 символов)
```
Официальный бот заявок VoidSMP и Майнкилд: контент-мейкер, хелпер, редактор Вики. Решение — в личку.
```

## Полное описание (до 512 символов)
Меню BotFather: **Edit Bot → Edit Description** (это не отдельная команда).
```
Официальный бот набора в команду проектов VoidSMP и Майнкилд.

Доступные роли: Контент мейкер (VoidSMP и/или Майнкилд), Хелпер, Редактор Вики (Fandom).
Выберите направление, ответьте на вопросы анкеты и дождитесь решения: оно придёт в личные сообщения с ботом. Заявки видят только администраторы проекта.
```

## /setcommands
```
start - Главное меню и подача заявки
my - Мои заявки и их статусы
help - Как подать заявку
about - О проектах и ролях
cancel - Отменить заполнение анкеты
id - Показать мой Telegram ID
apps - Список заявок (только администраторам)
```

> Список команд бот также регистрирует сам при запуске (`set_my_commands`),
> поэтому этот шаг можно пропустить — но лучше проверить, что он применился.

## Дополнительно
- `/setuserpic` — поставьте логотип проекта (квадрат, минимум 512×512).
- Privacy mode (`/setprivacy`) можно оставить включённым: бот работает только в личных сообщениях.
- Не запускайте второй экземпляр с тем же токеном — иначе Telegram вернёт `Conflict: terminated by other getUpdates request`.
